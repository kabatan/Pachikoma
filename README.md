# パチコマ (Pachikoma)

2026年10月28日のローカル既定構成を配布します。候補G（S/A/B/Cの4段賞＋参加賞）、自然物理の盤 F_natural_wide_return_v1_g_20261028、30秒の追加募集・回数無制限・スタッフ起動、m3/pack1026筐体を収録しています。
通常画面は ryugu1028、JPはタイトルv8・bg2fの連続背景・明るいルーレットです。発射、射出器の画像、映像の先読みとクロスフェードの修正を含みます。

Windows は Pachikoma-Play.bat を開いてください。Node.js が無ければ Windows 標準の PowerShell サーバーを使います。
macOS / Linux は `node work/game_demo/play/serve.mjs 8800` を実行し、表示されたURLをブラウザで開いてください。WebGL2対応の Chrome / Edge を推奨します。

- Space: 開始・説明を進める・発射。時間切れ後の募集では追加を申し込む
- A: 募集で追加を申し込む、B: 計数、C: 継続の選択、F: 全画面、R: 結果からリセット
- 追加申込後は100円チケットをスタッフへ渡し、スタッフが S キーで確認すると＋22秒・＋10玉で再開

既定の遊技が参照するファイルと起動用ファイル・ライセンスだけを同梱しています。JP映像の収録範囲は既定のmanifestに従い、初回の残り穴4を含みます。
未使用版・試作・バックアップ・テスト出力は含みません。LFSは使用せず、大きなプローブデータは対応ローダーが読める分割ファイルにしています。
フォントの利用条件は同梱のOFL、ライブラリは各LICENSEを参照してください。画像・音声・ゲーム独自コードの利用条件は未設定です。

ESP32と2個のLED付き押しボタンで筐体操作する場合は、[配線図とセットアップ手順](hardware/README.md)を参照してください（左ボタン＝開始・発射・継続、右ボタン＝確定・募集での終了）。
