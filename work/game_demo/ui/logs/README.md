# 匿名テストプレイ記録（2026-10-17〜18）

このスナップショットには、匿名の `playId` ごとに保存された73プレイ分のJSONを収録しています。68件は `completed`、5件は `in_progress` です。各JSONには入力回数、イベント履歴、持ち玉や賞玉などの結果が含まれます。

- `human/YYYYMMDD/<playId>.json`: 1プレイ単位の記録。日付はプレイ開始日のUTCです。
- `YYYYMMDD.jsonl`: 同じ期間にサーバーが記録した詳細イベントログ。人間のプレイ以外のシステムイベントも含まれます。

ゲームは引き続きこのディレクトリへ記録します。今回のコミット対象は上記の期間のファイルのみです。
