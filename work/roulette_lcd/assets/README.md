## 描画・合成

通常合成は SRC_ALPHA / ONE_MINUS_SRC_ALPHA。外光・ドーム・軌跡・点灯ランプ・針の光と
シートは ONE / ONE または screen。PNGの透明画素のRGBは0。加算PNGも端のalphaは0。
Pixi等がアップロード時にpremultiplyする場合は、素材がstraightであることと設定を一致させる。

- リム、ドーム、ハブ、面のアンカーは `(0.5, 0.5)`。リムの基準半径は1024px、
  内縁半径819.2px（0.80）。画像端の透明ガードのため外周の支持領域を約1.23px内側に収めた。
- 面4種は1024角、半径0.99。2048角の盤に合わせるときは倍率 `2 × 0.80 / 0.99`。
  扇形に切り抜いて使う。試し組みは90°ずつの4くさび。
- 目盛りは0°＝12時、時計回り7.2°間隔の50本、0・5・10…45が太い。
  花びらのくぼみは0・72・144・216・288°。目盛りと重ならない半径0.932に配置。
- 針と針光は1024×2048。アンカー `(0.5, 0.5)`、軸は `(512,1024)`、
  針先は `(512,27)`。本体の下半分は透明。盤2048角と同倍率で重ねる。
- 仕切りは `(0.5,1)` を軸として回す。盤2048角では高さ819.2pxに縮小。
  端は透明という条件のため底端1pxにガードを持つ。
- 影2560角は盤2048角と同倍率、中心を一致。影と赤い環境光は通常合成。
- ランプは尖った先端が上、二股の切れ込みが下。offを通常合成し、onを加算する。
- 軌跡は針が12時のとき反時計回り160°、半径0.55〜0.99。
  盤と同倍率・同心で、針と同じ角度に回す。
- 文字は各1800×640。アンカー `(0.5,0.5)` で3層を一致させ、影→外光→本体の順。
  `dup=重複`、`m1=−1灯`、`m2=−2灯`、`m3=−3灯`、`all=全消灯`。
- シートは各フレーム内に20pxの黒ガード。フレーム単位でClamp、UVは半テクセル内側、
  アトラスmipmapは無効。先頭／末尾コマは黒。

## 再生成

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python3 work/roulette_lcd/assets/generate_assets.py
```

`--part parts|text|fx|review` で区分再生成も可能。出力先はこのディレクトリのみ。
ローカルの numpy / Pillow / scipy / OpenCV と Noto Sans CJK Black を使用。
CPUの高さ場・表面法線・反射環境、距離場の面取り、押し出し側面で描画。
GPU・Blender・画像生成モデル・ネットは使用していない。

素材の最終的な演出上の評価・統括による目視QAは別途必要。
実装側のHTMLや既存素材には変更を加えていない。
