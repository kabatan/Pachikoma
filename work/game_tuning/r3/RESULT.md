# R3-T 調整結果（監督決定・10/19）

## 試遊設定

`config_r3.json` を案Bに設定した。持ち時間72秒、追加1回につき22秒・最大4回、発射間隔0.45秒。盤はCup 1・4を20mm、Cup 7を42mmとし、通常釘PIN_0082（x=102、y=−91mm）を配置。4〜5灯の重複保護は2回。

景品は参加賞／C／B／A／Sの5段。C=JP累計30、B=100、A=200。Sは500を実際に獲得した場合だけ。判定対象は即時JP配当と、確定した連チャン配当の合計。貸玉と未確定の連チャン配当は含めない。500のJPルーレット重みは4/1,000,000（各有償抽選あたり4ppm）。成功率11%の受け入れ判定は次回試遊まで保留する。

盤の物理測定はX揺らぎ0.5mm、速度揺らぎ3%、Y揺らぎ0、9,720球。Cup 1/2/3/4/5/6/7の割合は10.02/17.76/17.69/7.60/15.19/9.01/22.74%、判定不能0件だった。設定、盤、測定標本は本ディレクトリ内にある。

## 抑制案の比較（追加0回 → 4回）

賞率は各モデルの順に「適当連打／普通／上手い人」。どの案もSは500獲得時だけ。JP成功率は変更していない。

|判定案|C以上|B以上|A以上|
|---|---|---|---|
|現行：JP累計＋確定連チャン|18.6→41.4% / 31.2→56.0% / 40.8→75.0%|4.4→12.4% / 5.0→14.8% / 10.8→31.8%|1.4→4.0% / 1.4→3.4% / 3.6→8.2%|
|1回のJP連チャン最高額|18.6→41.4% / 31.2→56.0% / 40.8→75.0%|4.4→11.4% / 5.0→11.8% / 10.8→23.4%|1.4→3.8% / 1.4→2.8% / 3.6→6.0%|
|追加1回ごとにC/B/A境目を12.5%上げる|18.6→17.4% / 31.2→26.6% / 40.8→57.0%|4.4→4.8% / 5.0→5.0% / 10.8→13.8%|1.4→0.2% / 1.4→0.0% / 3.6→1.2%|

連チャン最高額案はC以上の増加を抑えず、B/Aの増加を一部抑える。境目調整案は追加4回でC/B/Aを45/150/300にする。C以上の増加を抑えるが、上手い人ではC以上が57%まで増え、B/A以上の率も追加0回よりわずかに高い。いずれも現行仕様を書き換える採用決定ではなく、監督が追加による賞率上昇をさらに抑える場合の比較測定。

## Sの低確率と試遊確認

Sは抽選1回あたり4ppm。500プレイではS獲得が0件だったため、実測頻度とはせず、通常JPと確定連チャンの有償抽選回数からプレイ単位の確率を計算した。100万プレイあたりの推定は、追加0→4回で適当連打0.92→2.18件、普通1.63→3.42件、上手い人2.62→6.09件。技能・追加で抽選回数が変わるため、全プレイ一律の「100万回に1回」にはならない。

次回試遊ではJP成功率を実測し、11%の目標を確認する。表示側への依頼事項として、景品メーターをC/B/A/Sの4項目に変更する（表示側は未実装）。
