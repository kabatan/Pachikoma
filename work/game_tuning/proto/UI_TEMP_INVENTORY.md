## 演出・3Dへの依頼
1. **賞玉の段と灯の数の表示**（旧UIの青緑パネルが担っていた）: いま当たると何玉か(1/2/3/12/30/JP)と、いまの灯の数。口のランプで灯の数は分かるが、段(賞玉)が出る所がない。液晶の常時の隅か、3Dの表示に置いてほしい。
2. **待機中の開始の案内**: 液晶の待機演出に「ひかる ボタンを おしてね」の類を出す（旧UIの「SPACEで100円スタート」を消したため）。
3. **ボタン**: 液晶の案内は筐体の外のボタン(左=射出、右=勝負)を指す。筐体3Dにボタンの形はなく、画面にも出さない(決定)。画面にボタンを出すかはユーザー判断。
4. 計数の確認箱と係員呼び出し箱を、液晶か3Dの表示に置き換えるなら依頼（優先度は低い）。
