# JP チャンス導入の雷の音（10/31）

## 出典の記録
- 手本（監督提供）: 東京喰種 先バレ音 `work/effects/r4_h_fx/jp_start_1031/ref_audio/sakibare_01_tokyoghoul.wav`（4.7秒・44.1kHz ステレオ・平均 -10.5dB・最大 0dB）。
  **この音のサンプルは一切使っていない**。構造（下の表）だけを聞き取り・解析して写し、別の音として合成した。
- 新しい音 `jp_thunder_new_1031.wav`（2.1秒・48kHz ステレオ・最大 -0.3dBFS）は `synth_thunder.py`（numpy/scipy）で、全部合成。外部素材・AI 生成の素材なし。

## 手本から写した構造 / 変えた所
| 項目 | 手本（東京喰種） | 新しい音 |
|---|---|---|
| 立ち上がり | 頭から全開（立ち上がりなし） | 同じ。0サンプル目から全開（映像の雷の閃光と同じコマ） |
| 帯域 | 中域 300-1.5k が主、高域 6-16k が続き、低音は弱い | 同じ配分（中域・高域主体）。低音は「頭の落下」だけ別に足した |
| 中身 | 下降する笛＋揺れる低い倍音の和音 | 下降する「裂ける」帯域ノイズ（9k→1.4kHz、90Hz のノコギリ波で AM）＋歪ませたノコギリ和音（根音 69.3Hz=C#2＋5度＋オクターブ、3半音下降・揺れ付き）。音高・音色とも別 |
| 頭の衝撃 | なし（広帯域の壁） | 三連のひび割れ（0 / 85 / 210ms）と、サブの落下 110→34Hz を足した（低音の衝撃） |
| ステレオ | 非常に広い（side/mid 1.7） | 同等（2.0）。左右で別系列のノイズ＋逆相成分 |
| 長さ | 壁が約2.1秒で突然切れる | 雷の映像（1.0秒）に合わせ 1.0 秒で突然切る |
| 余韻 | 約0.33秒ごとの段で落ちるゲート残響 約2秒 | 0.2秒ごとの段（-7dB ずつ）の疑似残響 約1.1秒（JP曲の入りへ重なる） |
| 音量 | 平均 -10.5dB・最大 0dB に張り付く | 壁の RMS -8.2dB・最大 -0.3dBFS（ソフトクリップ） |

## 鳴らし方（`lcd_surface/jp_start_1031.mjs`）
- 6灯目の瞬間に、音の時計で一度に予約: 通常の音（`engine.mix`＝BGM・SE・玉の音）と JP の出口（`engine.hot`）を 0.5 倍へ（揃いの一撃は残す）→ 0.06 倍（止め：静か）→ 雷の直前 0（無音）→ 雷の間 0 → 雷が切れるころ元の音量へ戻す（JP曲の入りと重なる）。
- 雷は圧縮機の後（`engine.master` の入口、+6.3dB 固定）へ直接入れる。絞りの対象にならない。
- `jp_audio_v5` の既存の雷・前触れ・閃光の素材（`v3_thunder`/`v3_thunder_flash`/`zap_flash`/`v3_pre_swell`）は、実行時に無音の素材へ差し替える（`jp_audio_v5.mjs` 自体は無改変）。
- `?jpstart_snd=0` で音の変更をすべて止める（鼓動・雷・絞りなし、既存の v5 の雷のまま）。`?jpstart=0` で導入全体が従来どおり。
