# 超つくこまRUSH・継続の決めの音の底上げ(11/1)

監督: 「紫の雷は最大音量で迫力があるが、超つくこまRUSHや継続の時の音は足りない。実機を参考に迫力のある効果音を」。

## 仕組み(`work/audio/runtime/loud_fx_1101.mjs`、`?fxloud=0` で読まない=従来の音)
- 雷(`jp_start_1031.mjs`)と同じ: 新しい音は圧縮機の後(`engine.master` の入口、+6.3dB 固定)へ直接入れ、決めの前後だけ他の音(`engine.mix`・`engine.hot`)を絞る。
  絞りは「その瞬間だけ」: 決めの手前から約0.02秒で沈め、保って、戻す(深さ 8〜34dB)。常時鳴る層は作らない。決めの1コマ手前は一瞬ほぼ無音(溜め)。
- 場面は `lcd.jp.where()`(name・serial・w.time)を読むだけ。出来事の表は `cues.json`(f=元の映像のコマ)。fx_trim の skip(飛ばすコマ)は場面の manifest から読んで差し引く。
  skip の先の出来事は、映像が飛び先に着いて2コマ進んでから予約する(録画機では飛んだ直後に最大0.4秒の止まりがあり、音が先走らないように)。
- 音は起動時にデコードするだけ(プレイ中の合成なし)。`window.__loudFx`(log/played/enabled)で確認でき、`enabled=false` で一時的に従来へ戻せる。
- 対象の場面: `jp_rush`(超つくこまRUSH)、`chain_announce_cutin`(継続カットイン)、`chain_success`(継続成功)、`chain_jp_land_d*`(継続の着地)。
  触っていない: `after_jp_sound_1029.mjs`・`fx_trim_1030.mjs`・`final_result_surface_20261029.mjs`・`effects_bus.mjs`・`jp_audio_v5.mjs`・`audio_lift_1031.mjs`・`jp_start_1031.mjs`(既存の音はそのまま鳴り、決めの瞬間だけ絞られる)。

## 作りの手本(実機パチンコの決めの構成。音そのものは写していない)
1. 頭に低音の衝撃(キック+サブの落下)。ただし実機は 60Hz 以下がほぼ無い(測定済み)ので 45Hz 以下は切り、120Hz 前後〜を主に。
2. 同時に金属の打撃(ゴング/アンビルの非整数倍音)とスネア状のひび(1.5〜9kHz)。
3. ブラスの長三和音(オクターブ重ね。明るさが頭で開く)+ティンパニ。RUSH=D、継続=A(JP曲の根音 D の完全5度上)。「超→つくこま→RUSH」は根音が D→F#→A→D(上のオクターブ)と上がって決まる。
4. 直後にシンバルのクラッシュ(最大の決めは頭の前に逆回転の吸い込み)と、金属の雨(きらめき)。
5. 決めの前は溜め: 上昇音(ライザー。尾は最大のまま切る)で詰め、映像の白黒のストロボ(継続成功の 118〜126 コマ)には15Hzの刻みを合わせる。
6. 全体を強く飽和させて音の密度を上げる(実機は RMS -8dB 前後・ピークは 0dBFS に張り付く)。帯域配分は実機成功音の平均(`TARGET_WIN`)へ寄せた。
段の差: 最大の決め(RUSH・継続の完成)=雷と同等、他の叩きつけ=-3〜-4dB、小さな点火=-6dB。

## 実測(実機チェーン: master → 天井 .8·tanh(2x) の出力を録音)
`src/meas.py`(BS.1770 K特性)、`src/report.py`(素材ごと)。ゲーム(rules=h)を動かして最終段を録った数字は NOTES 末尾ではなく報告に記載(`scratch_1031/loud_sfx/lab/stats.py`)。

## 再生成
`python3 src/synth_loud.py [名前...]`(tools/heavy.sh 経由)。出力 `sfx_wav/`(確認用)・`sfx_ogg/`(実行時)・`meta.json`(頭の位置 anchor)。

# 第4版 `?jpmix`(既定・11/01 夜): JP全体をRUSHの系統へ揃える + 配当獲得の音
監督(1): 「成功時の音だけ浮きすぎ。JPチャンスやJP全体も実機の音響を参考に」→ (2)追加: 「RUSHの効果音はいい感じ。それに合わせてパチンコっぽく。配当獲得の演出にも最大音量の派手な効果音を」。
**RUSH(`lf_r_rush_*`)は変えない**。JPチャンスと継続を同じ系統(純音の高音・キュイン・同じ音量感)に揃え、配当獲得(reward_30/40/100/200/500)に最大音量の音を足した。
旗: `?jpmix=0` で今まで(RUSH・継続の既存の音だけ)へ戻る。`?loudkind=j` は調(JP曲の D/A 長調)に合わせて作り直した試作(下記「j 版」。既定ではない)。`?fxloud=0` は全部従来。
実装: `work/audio/runtime/loud_fx_1101.mjs`(`cues_mix.json` を `cues.json` に足すだけ。RUSH・継続の既存の項目・音は変更なし)。素材は `src/synth_pay.py`(`lf_r_pay_*`・`lf_r_up1..3`・`lf_r_chance`)。
足した出来事(`cues_mix.json`): 封印が1枚切れる `jp_aim_seal_dN_b1/b2/open`(継続は `cseal_*`、-1dB)→ `lf_r_up1/2/3`(キュインが 1kHz→2kHz→4kHz へ上がり、低音の衝撃が段ごとに大きくなる)、題字 `jp_chance_dN` → `lf_r_chance`、
配当 `reward_N`(f3 頭・f46 一撃・f109 全景・f139/163/187 閃光)→ `lf_r_pay_open/hit{0..4}/full{0..4}/flash`。tier 0..4 = 30/40/100/200/500。段が上がるほど低音・線の長さ・上昇・コインの雨が増え、500 が最大(RUSH と同等〜-0.5dB)。
絞り(BGM を沈める)は決めの瞬間だけ(深さ 14〜18dB・0.3〜0.9秒保って戻す)。30・40 の短縮版(skip [[3,27],[47,109]])は f3 の頭を鳴らさない。

## JP通しの録音で見えた「成功時だけ浮く」原因(数字。聴感は未確認)
録り方: ゲーム(`rules=h`)を通しで遊び(6灯→雷→JPチャンス→メーター連打→ルーレット→配当→継続)、最終段(ceiling)をサンプル精度で録音(`scratch_1031/jp_mix/lab`)。`jpmix`導入前の既定(r 版)の数字:
| 場面 | momentary 最大 LUFS | 備考 |
|---|---|---|
| JPチャンスの土台(JP曲)| -10〜-11 | |
| 紫の雷 | -1.2 | |
| **jp_rush(RUSH)** | **-0.8**(`fxloud=0` では -9.6) | 土台より約 9〜10LU 上、帯域配分は 2〜6kHz が -3.7dB(最大)・120〜500Hz が -14.8dB |
| 継続カットイン | -3.5(`fxloud=0` では -13.8) | |
| ルーレット -8.5 / 配当(reward_30)-6.0 | | 階段の「次」が RUSH(-0.8)より 5〜8LU 低い |
- 音高: 持続の純音(1000/2000/4000Hz)は B5 より +21セント高い。JP曲は A=440(測定 +4セント)なので JP曲の B と約12Hzで唸る。継続の階段(A#5/C6)は A/D 長調の外の音。
- JP曲の調とテンポ: テンポ 170.37 BPM(1小節 1.4087秒)。クロマは A .20 / E .13 / D .12 / G .11 / B .09 / F# .08(Krumhansl: A長調 .84、D長調 .78)。主音は D と A(ベースは D,G,B,F#,E,A)。
- 持続: RUSH 直後、4kHz の純音が全体から 12dB 以内で 3.0秒(最大で全体と同じ -0.3dB=その瞬間はほぼ4kHzの線だけ)、1kHz が 6.7秒。純音の線は耳の感度が最も高い 1〜5kHz にあり、BGMを沈めると裸で残る。
- 帯域: 実機の成功音(`audiolift_1031/REFERENCE.md`)は 250〜500 が -12〜-17dB、2〜4k が -5〜-7dB、4〜8k が -9〜-12dB。r 版は 2〜6k に集中。
- 飽和: 実機チェーン(+6.3dB → master 0.45 → 天井 0.8·tanh(2x))を通した非線形成分は信号に対し -14〜-18dB(素材のピークが 0dBFS 近く)。素材を 1.5dB 下げるごとに約 2.2dB 減る(音量とのトレードオフ)。
- ※監督の判断で RUSH は基準(変更しない)となったため、上の差は「RUSH の系統に周りを揃える」方向で使った(RUSH の純音の系統・音量感に配当・封印・題字を合わせた)。

## 実機の書き起こし(JP中の音の組み立て)。出典は LICENSES.md。解析のみ・録音は使っていない
1. 決めの前〜決め(プレミアム海物語の大当たり。LGvui_n0Hz0 22.5秒・pc6SFDJ8RV8 41.6秒): BGM -20〜-22 LUFS が決めの約0.3秒前から消え、0.26〜0.35秒の完全な無音 → 決め音(和音の持続 3.3秒、momentary -16〜-18 で BGM より +3〜4LU、120Hz〜2kHz 集中・2〜6kHz は帯域配分 -22dB・60Hz以下なし、約4〜5Hz の揺れ)→ 約1秒かけて消える → 1.5秒後に単音の鐘(1.0k+1.3kHz)。決め音は C長調の三和音(E4 C4 G4 と C6・E6)で、BGMの調とは関係ない。BGMは決め音の下には残らない。
2. 決め前の BGM の扱い(海物語大当り集 ZpcOrBIlXC8): 決めの1〜1.5秒前に BGM を約9dB 沈め、その上に上昇チャープを重ねて決めへ入る。決め音の momentary 最大は -5.6 で一定(BGM -9.8〜-12.4 より +4〜+7LU)。
3. 前兆から決めへの上昇(北斗の拳5 虹色CHANCE DYcMdc_Tuac、ガンダム hpDjkStR5F8 の 94〜105秒): 音量が約 25秒かけて -18〜-21 → -11〜-12 LUFS へ(+7〜+9LU)、重心が 1.5kHz → 3.4kHz へ。ガンダムは BGM が -25 → -13(約7秒)と上がり、決めの 1.5秒前から約30dB 落とし、途中に低い落下の一撃、0.14秒の無音のあと決め=新しい区間が全開(-7LUFS・70Hz〜8kHz に密)で始まる。決めの後も同じ音量が10秒以上続く(一撃で終わらず、状態が変わる)。
4. 配当獲得(ユニコーン 3000発Fever 76vLrRMJb90 の 23.7〜41.7秒、約18秒): momentary -3 LUFS で一定。矩形波の低い階段(220〜440Hz、約8音/秒)・1kHz と 3.7kHz の純音の線(3〜4秒保つ)・2kHz→500Hz の下降チャープ(ピュン、0.3秒)・110Hz→1.3kHz の大きな上昇(約2秒)の繰り返し。終わりは 0.2秒の無音の後、3.7kHz の線+下降チャープ+低音のうねりで締める。→ `synth_pay.py` の `P_full`(階段・下降チャープ・上昇・線・コインの雨)へ反映。
5. 連打中の音(本回では実機の素材を見つけられず未書き起こし。既存の連打/メーターの音は変更なし)。
