測定ツール: `tools/measure.mjs`。帯域は 50-100 / 100-200 / 200-400 / 400-800 / 800-1.6k / 1.6-3.2k / 3.2-6.4k / 6.4-12.8k / 12.8-20k Hz、値は全エネルギーに対する各帯域のdB。

## 測定から分かったこと

1. 電子SE5本の平均は 100〜800Hz に厚みがあり、800Hz〜3kHzが最大(`TARGET_SE`)。前の自作音は400Hz以下がほぼ無音で薄かった。
2. 実機SEの波形は詰まっている(ピーク/RMS = 8〜16dB)。素の合成は16〜20dB。
3. 激アツ系は2.5〜3.5秒、包絡がほぼ平らに続く。前の自作音は0.7〜1.5秒の減衰だった。
4. 玉の音は200〜1600Hzにも厚みがある。r2エンジンの物理音側の高域通過(3kHz)は実機と合わない。

## 測れていないもの・限界

- 私(Claude)は音を聴けない。実機に「聞こえるか」は人の耳で確かめるしかない。
- 圧縮された動画音声なので15kHz以上は欠落している。
- 測ったのは機種ごとに作りの違うSE数本。特定の1機種の音ではない。
- 釘に当たる単独の音・入賞口の音・ルーレットの回転音の孤立した録音はまだ測れていない(`brass`は玉がガラスに当たる測定、`resin`は推定)。

ユーザーの録音(仕上げ前): `-24,-21,-10,-13,-5,-4,-12,-19,-37`、重心 2.9kHz、完全モノラル。
→ 50〜200Hzが15〜20dB足りず、800Hz〜3.2kHzが約8dB出すぎ(中域に寄った箱鳴り)、3.2kHz以上も相対的に約6dB弱い。これが「録音特有のくぐもり」。

仕上げ(`tools/master_bgm.mjs`): ノイズ低減 → 70Hz以下カット → 帯域を実機BGM平均へ寄せる(中域-10dB、低域+3〜4dB、高域+) → 高域の倍音(エキサイター)で空気感 → 軽い圧縮 → 擬似ステレオ(L/R相関0.76) → 音量(-22.5dB RMS)。
仕上げ後の帯域: `-13,-10,-5,-9,-9,-7,-11,-15,-27`(目標との差3.7dB)。
### 録音の診断(PCのスピーカーから流した音をスマホで録ったもの)

- 長時間平均で、**300Hz以下は曲の無い末尾の雑音床と同じレベル**。スピーカーが低音を出さないので、低音は録音に存在しない。
- 300Hz以上は雑音より20〜30dB大きく、倍音の線も鮮明(反響のにじみは小さい)。高域は雑音床の下で、きれい。
- 24秒(16小節)後の繰り返しは波形が一致しない(相関0.06〜0.4、無関係な位置と同程度)ので、重ねて雑音を消す方法は使えない。
- 試して採用しなかったもの: ①Fのペダル低音(聞くと雑音になった。低域の雑音も持ち上げていた)、②コードのルート検出(F・C・Gに偏り、16小節周期の一致率0.6〜0.7で不安定)、③録音の最低音(200〜800Hz)を追跡して1オクターブ下を足す(F4・G4が1拍ごとに揺れ、G5へ跳ぶ。メロディを拾っていて周期の一致率0.45)。
- 採用: 200Hz以下を切って雑音を除く(低域の持ち上げもやめる)+ 雑音除去を少し強める + 中高域の帯域整形・倍音・軽い圧縮・擬似ステレオ。**低音は録音からは戻せない。**元の音源ファイルがあれば録音劣化は丸ごと消せる。

## 各音の手本(どの測定を何に使ったか)

| 音 | 手本にした実機音(測定した数値だけを使用) | 自作の部分 |
|---|---|---|
| 点灯1〜3 | 電子SE5本(赤保留・先ローリング・先バレ・昇格・金レバー)の帯域配分の平均 → さらにBGMの隙間のため400Hz〜6.4kHzを抑制 | 旋律(F majorの上行アルペジオ)、音色 |
| 4〜6灯 | インデックス2 赤保留、ユニコーン2 金レバー(帯域・2.5〜3.5秒の持続・波形の密度) | 旋律・和音(F→C)・きらめき |
| ルーレット | インデックス2 先ローリング(倍音の多い鋸歯が滑り下りる帯域) | 回転の刻み、ループ化 |
| 昇格 | ボタン準備中からレバーに昇格する演出の音(エヴァ)の帯域 | 上行の音列 |
| 発射 | 「パチンコ玉の音を抽出」のハンマー(50〜200Hzの低い衝撃+高域のクリック) | |
| 釘・玉・ゲート・樹脂 | 同動画の「玉がガラスに当たる」「玉の山」の帯域を土台にしたが、**聴いて気持ちいいことを優先して実測から離した**(高域を丸め、当たるたびにF majorのペンタトニックの「チン」を足す) | ペンタトニックの音、胴鳴り(樹脂は実測なし) |

| 重複・入賞口・外れ・皿あふれ・残り10秒・開始・貸し玉・追加 | **直接の手本なし**。電子SE平均の帯域(BGM用に調整)と、玉の山の帯域だけを適用 | ほぼすべて |

## 更新: クリーンな音源への差し替え(2026-10-29)

スマホ録音の補正(上の診断・帯域整形・低域の処理)は、パソコンの内部で録音した劣化のない音源(`normal_clean.wav`、24bit・48kHz・ステレオ、ピーク-1dB、割れなし)を使うことで不要になった。`bgm/user/normal_loop.ogg` は現在この音源から作っている(`tools/build_bgm.mjs` の `buildBgmClean`)。曲には触れず、音量(-22.5dB RMS)とループだけ整えた。

- 音源の帯域配分: `-10,-7,-7,-7,-8,-11,-14,-20,-33`(実機BGM3本の平均 `-6,-7,-8,-10,-13,-12,-13,-18,-30` に近い。100〜200Hzにも本物の低音が入っている)。
- テンポ 160.18BPM、0小節目=音源の4.9548秒。曲の区切りは10・26・42・58・74小節(16小節周期)。ループは10〜58小節の48小節(約72秒)、導入は先頭〜10小節(約15秒)。継ぎ目は0.75秒のクロスフェード。繰り返し部分は波形が一致しない(相関0.1〜0.4)ため、小節線に合わせた長さで切っている。
- SEとの重なり(SE−BGM、200Hz〜3.2kHzの最大): 通常のSEは3〜7dB、4〜6灯は9〜10dB(エンジンのBGM -5dB duckと併用)。
